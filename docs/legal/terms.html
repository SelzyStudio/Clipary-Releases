2. 무료 이용과 사용 권한

  1. 이 배포본의 CLIPARY 자체 기능은 무료로 제공됩니다. CLIPARY 회원가입, 유료 라이선스 구매, 라이선스 키 등록 또는 후원을 요구하지 않습니다.
  2. 사용자는 개인 또는 업무·상업 목적으로 CLIPARY를 설치하고 사용할 수 있습니다. 사용 PC 수를 유료 라이선스로 제한하지 않습니다.
  3. 무료 사용 권한은 소스 코드 공개 또는 소스 코드 사용 권한을 뜻하지 않습니다. 운영자가 보유한 CLIPARY 코드와 상표에 관한 권리는 별도로 유지됩니다.
  4. 운영자의 별도 허락 없이 CLIPARY 자체를 유료로 재판매하거나, 운영자가 승인한 것처럼 표시하거나, 운영자 소유 코드를 무단으로 복제·수정·배포해서는 안 됩니다. 다만 관계 법령이 허용하는 행위와 제3자 오픈소스 라이선스가 허용하는 행위는 제한하지 않습니다.

3. 화면·음성·파일 처리

  1. CLIPARY는 사용자가 실행한 캡처·녹화·편집·합성·OCR·노트 저장 작업에 필요한 화면, 선택한 파일 및 관련 정보를 처리합니다. 녹화 설정에 따라 시스템 소리와 마이크 음성이 포함될 수 있습니다.
  2. 사용자는 캡처·녹화 대상과 파일에 관한 저작권, 개인정보, 비밀유지 의무 및 필요한 동의를 확인해야 합니다. 타인의 개인정보를 외부 AI에 보내려면 적법한 권한과 필요한 동의를 확보해야 합니다.
  3. 자동 저장, 프로젝트 복구 사본, 노트 보관함, 클립보드와 진단 로그에는 작업 내용 또는 경로 등이 남을 수 있습니다. 저장 위치와 삭제 방법은 개인정보처리방침을 따릅니다.
  4. 사용자는 중요한 원본을 별도로 보관하고, 합성·OCR·AI 생성 결과를 확인한 뒤 이용해야 합니다.

4. 선택형 외부 AI 기능

  1. AI 정리와 AI 텍스트 인식은 사용자가 선택한 Claude Code, Codex CLI 또는 Gemini CLI를 실행하여 외부 제공자의 서비스를 이용하는 기능입니다. 기본 텍스트 인식은 PC에서 동작하는 내장 Tesseract OCR입니다.
  2. 외부 AI를 실행하면 선택한 이미지와 분석 지시문이 해당 CLI 및 AI 제공자에게 전달됩니다. 앱은 전송 전에 제공자와 전송 항목을 안내하고 사용자의 확인을 받습니다. 전송을 취소하면 해당 AI 요청을 실행하지 않습니다.
  3. 외부 CLI는 별도 프로그램입니다. 사용자가 연결을 선택하면 설치 확인 후 공식 설치 프로그램 또는 npm을 통한 설치와 제공자 로그인 절차를 진행할 수 있습니다. 사용자의 계정·구독, 이용 한도와 별도 요금은 제공자의 조건을 따르며 CLIPARY의 무료 이용 또는 후원에 포함되지 않습니다.
  4. 사용자는 외부 AI를 사용하지 않거나 내장 OCR만 선택할 수 있습니다. 이미 외부 제공자에게 전달된 정보의 열람·삭제·학습 이용 설정은 해당 제공자의 절차도 확인해야 합니다.

제3자 소프트웨어에는 그 라이선스가 우선 적용됩니다. 이 약관의 소스 비공개, 복제·수정·재배포 및 기타 제한은 해당 라이선스가 부여하는 권리를 축소하지 않습니다. 특히 GPL 구성요소의 소스 제공 등 의무는 CLIPARY 자체 코드의 비공개 방침과 구분하여 이행해야 합니다.
