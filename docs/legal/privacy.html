3. 외부 AI: 전달 항목, 선택과 통제

  1. 수신자와 목적: 사용자가 선택한 Anthropic의 Claude Code, OpenAI의 Codex CLI 또는 Google의 Gemini CLI와 그 제공자가 이미지의 텍스트 인식 또는 AI 정리를 처리합니다. CLIPARY 운영자의 AI 프록시 서버를 거치는 방식이 아니라 사용자의 PC에 설치된 CLI를 실행하는 방식입니다.
  2. 전달 항목·시점: 외부 AI 요청을 실행할 때 선택한 이미지 파일과 앱이 만든 분석 지시문이 CLI에 전달되며 제공자 서비스로 전송됩니다. 이미지에는 화면에 보이는 개인정보·문서·대화가 포함될 수 있습니다. CLI는 서비스 이용을 위해 계정·인증·IP·기기·사용 기록 등도 자체 정책에 따라 처리할 수 있습니다.
  3. 사용자 확인: 앱은 AI 요청마다 선택한 제공자와 이미지·지시문 전송을 안내하고 확인을 받습니다. 취소하면 해당 요청을 보내지 않습니다. 새 사용자의 기본 OCR은 내장 Tesseract이며, 기존 사용자가 저장해 둔 AI OCR 설정은 유지될 수 있어도 외부 전송 확인 절차는 적용됩니다.
  4. 설치·로그인·연결 확인: 사용자가 AI 연결을 선택하면 설치 확인 후 Anthropic 공식 설치 프로그램 또는 npm 배포처에서 외부 CLI를 설치하고 제공자 로그인 화면을 열 수 있습니다. 로그인과 인증 정보는 외부 CLI가 관리합니다. Gemini의 로그인 확인은 화면 이미지 없이 짧은 테스트 요청을 보냅니다. 선택된 Gemini CLI를 사전 시작하거나 연결 상태를 확인할 때도 해당 CLI가 서비스에 접속할 수 있습니다.
  5. 보유·국외 처리: AI 요청·응답, 인증 정보와 CLI 세션 기록의 저장 위치, 보유기간, 모델 개선 이용 여부 및 국외 처리 조건은 제공자·계정 종류·설정에 따라 달라집니다. CLIPARY에서 임시 파일을 지워도 CLI 또는 제공자 기록이 함께 삭제되는 것은 아닙니다. 제공자의 현재 방침과 계정 설정을 확인하십시오: Anthropic, OpenAI, Google.
  6. 거부·철회: 전송 확인을 취소하거나 설정 → AI → 텍스트 인식에서 내장 OCR만 (Tesseract)을 선택하고 AI 정리를 실행하지 않으면 이미지의 AI 전송을 피할 수 있습니다. CLI의 로그아웃·제거와 이미 전송한 기록의 삭제는 해당 CLI·제공자 절차도 이용해야 합니다. 동의 거부로 일반 캡처·편집·녹화·내장 OCR 이용을 제한하지 않습니다.

외부 AI를 사용하기 전에 선택 이미지에 타인의 개인정보, 건강·금융 정보, 비밀번호 또는 비밀 자료가 포함되었는지 확인하고 필요한 권한과 동의를 확보하십시오. 일반적인 전송 확인만으로 타인의 동의나 법령상 필요한 별도 동의가 모두 충족되는 것은 아닙니다.
