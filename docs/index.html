실제로 이렇게 작업합니다

실제 CLIPARY 화면입니다. 이미지를 누르면 크게 볼 수 있습니다.

설치 후 바로 시작

첫 캡처는 세 단계면 됩니다

  1. 실행하고 단축키
    Ctrl+Shift+P를 누릅니다.
  2. 원하는 부분 선택
    영역은 드래그, 창은 클릭합니다.
  3. 설명하고 붙여넣기
    주석을 넣고 Ctrl+Shift+C로 복사합니다.

기능별 사용법

1. 필요한 화면만 캡처하고 바로 공유

  1. Ctrl+Shift+P를 누릅니다.
  2. 드래그로 영역을 고르거나 창을 클릭합니다.
  3. 문서·메신저에서 Ctrl+V로 붙여넣습니다.

2. 화살표·번호·모자이크로 설명을 끝내기

  1. 캡처나 이미지 파일을 편집 화면에서 엽니다.
  2. 화살표·텍스트·번호를 넣고 필요한 부분을 가립니다.
  3. Ctrl+S로 저장하거나 Ctrl+Shift+C로 복사합니다.

3. 긴 웹페이지·대화 캡처를 한 장으로

  1. 페이지를 직접 스크롤하며 인접 화면이 20~40% 겹치게 캡처합니다.
  2. 이미지 목록의 순서를 맞추고 합성 모드를 고릅니다.
  3. N장 합치기를 누른 뒤 결과를 저장합니다.

4. 화면을 녹화하고 MP4·GIF 사용법 영상으로

  1. 상단 녹화에서 모니터·창·영역을 선택하고 시작합니다.
  2. 정지 후 편집기에서 Ctrl+B로 나누고 Q/W로 앞뒤를 다듬습니다.
  3. 효과 추가로 안내를 넣고 내보내기에서 MP4 또는 GIF를 고릅니다.

5. 다시 타이핑하지 않고 이미지 글자 추출

  1. 결과 이미지에서 텍스트 인식을 엽니다.
  2. 내장 OCR을 선택해 실행합니다.
  3. 결과를 확인·수정하고 복사하거나 메모에 저장합니다.

6. 캡처를 잊지 않도록 Markdown 노트로

  1. 이미지 결과 화면의 메모를 누릅니다.
  2. 제목·내용을 적고 필요하면 OCR 결과를 함께 저장합니다.
  3. 노트 탭에서 검색하거나 관련 노트를 링크로 연결합니다.

7. 비교 이미지·콜라주를 한 페이지에 배치

  1. 이미지 파일을 끌어 놓거나 파일 선택으로 추가합니다.
  2. 단순 합치기를 열고 캔버스 크기·배경·여백을 정합니다.
  3. 이미지를 배치하고 설명을 더한 뒤 저장합니다.

8. 필요할 때만 외부 AI로 캡처 정리

  1. 설정의 AI에서 사용할 제공자의 도구와 계정을 연결합니다.
  2. 이미지의 AI 정리를 선택하고 전송 내용을 확인합니다.
  3. 결과를 검토·수정한 뒤 메모에 저장합니다.

사용 전에 알아두세요

  • 긴 화면 합치기는 사용자가 직접 스크롤하며 겹치는 캡처를 모으는 방식입니다. 자동으로 페이지를 스크롤하지 않습니다. 같은 배율로 찍고 20~40% 겹치게 하면 정합에 도움이 됩니다.
  • 내장 OCR은 PC에서 동작합니다. 외부 AI는 별도 계정·CLI·제공자 조건과 비용이 적용될 수 있고, 확인 후 선택한 내용이 외부로 전송됩니다. AI 정리는 현재 한국어 Markdown으로 제공합니다.
  • 모자이크·OCR·합성 결과는 공유 전 확인하세요. 기본 단축키는 설정에서 바꿀 수 있으며 앱에서 F1을 누르면 자세한 도움말을 볼 수 있습니다.

자주 묻는 질문

후원해야 사용할 수 있나요?

아니요. 현재 버전은 무료입니다. 후원은 개발을 응원하는 자율적인 지원이며 사용 권한, 광고 제거, 우선 지원 등의 보상을 판매하지 않습니다.

회사·학교에서도 사용해도 되나요?

네. 개인·기업·교육기관에서 무료로 사용할 수 있습니다. 자세한 사용 조건과 오픈소스 구성요소의 권리는 이용약관을 확인해 주세요.

무료이면 소스도 공개되나요?

CLIPARY 자체 소스는 비공개로 유지합니다. 포함된 오픈소스 구성요소에는 각 라이선스가 적용되며, 필요한 소스 제공과 고지는 별도로 준비합니다.

캡처 이미지가 외부로 전송되나요?

캡처·합성·OCR·일반 편집은 PC에서 수행합니다. 선택형 AI 기능을 실행하면 사용자가 선택한 이미지·텍스트·지시문이 외부 AI 도구와 제공업체에 전달될 수 있습니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

후원 결제나 기존 구매 내역은 어디로 문의하나요?

Ko-fi·PayPal 또는 카카오페이 송금 QR은 후원 안내에서 선택할 수 있습니다. 기존 구매나 후원 내역 문의는 selzystudio@gmail.com으로 보내 주세요. 환불·취소 안내도 확인할 수 있습니다.
